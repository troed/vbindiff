# VBinDiff openSUSE Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a public OBS home project that builds and serves `vbindiff` 3.0~beta5 for openSUSE Tumbleweed and Leap 16.0 from the fork `github.com/troed/vbindiff`.

**Architecture:** Five small commits on the fork's `opensuse` branch make the tree buildable from git without submodules; a single `vbindiff.spec` builds it; a `_service` pins the branch head and lets OBS generate the tarball. No patches live in the spec.

**Tech Stack:** autotools, C++, ncurses, RPM spec, OBS source services (`tar_scm` + `recompress`), git.

**Spec:** `docs/superpowers/specs/2026-11-01-vbindiff-opensuse-package-design.md`

## Global Constraints

- `Version: 3.0~beta5` exactly. Never `beta6`, never a new upstream-looking number.
- Release number is OBS's; the spec sets `Release: 0` and never a hand-maintained counter.
- No `.patch` files in the OBS package: every code change is a commit on `opensuse`.
- `opensuse` is append-only: no rebase, no force-push, ever.
- `License: GPL-2.0-or-later`; the package ships the licence as `%license COPYING`.
- Fork URL is `https://github.com/troed/vbindiff`; OBS project `home:troed:vbindiff`; repos `openSUSE_Tumbleweed` and `16.0`, architectures `x86_64` and `aarch64` only.
- The sandbox has `git`, `rpmbuild`, `rpmspec`, `gcc`, `g++`, `make`, autotools and `pod2man`, but **no** `osc`, `zypper`, `rpm2cpio`, ncurses headers, or Perl `Template` module. No `sudo`. Egress allows `github.com` and `cdn.opensuse.org`; `api.opensuse.org` is **not** allowed. Steps that need OBS or a Tumbleweed toolchain are executed by the human, and are written as such.

## Review Focus

- **Tarball name vs `%{version}`:** `3.0~beta5` puts a `~` in the source filename; if `%autosetup`'s default `-n %{name}-%{version}` does not match the tarball's top directory, `%prep` fails. Pinned by the `rpmbuild -bp` step in Task 4.
- **Man page generation:** `vbindiff.1` is generated by `tools/genfile.pl` (Perl Template Toolkit) during `make`; a missing `perl-Template-Toolkit` turns into a build failure, and a `%files` entry for a man page that was never installed is a packaging error. Pinned by the `%files`/buildlog checks in Tasks 2 and 4.
- **Vendoring incomplete:** if `GetOpt` stays a gitlink, `git archive` (and therefore the OBS tarball) contains an empty directory and the compile fails. Pinned by the archive-listing step in Task 1.
- **Version self-report:** after editing `AC_INIT`, the binary and the generated man page must both say `3.0_beta5`, matching the package. Pinned by the run step in Task 4.
- **openSUSE header layout:** `panel.h` lives under `/usr/include/ncurses` on openSUSE; PR #23 is what makes configure find it. Pinned by the Tumbleweed **and** 16.0 build checks in Task 5.

### Task 2: Write the spec

**Files:**
- Create: `packaging/opensuse/vbindiff.spec` (author it here, in the fork; copy it to the OBS package in Task 5)

**Interfaces:**
- Consumes: tarball `vbindiff-3.0~beta5.tar.gz` whose top directory is `vbindiff-3.0~beta5`.
- Produces: a spec that installs `/usr/bin/vbindiff` and a compressed `vbindiff.1`, ships `COPYING` as `%license`.

- [ ] **Step 1: Write the spec with these exact fields**

```
Name:           vbindiff
Version:        3.0~beta5
Release:        0
Summary:        Visual binary diff
License:        GPL-2.0-or-later
URL:            https://www.cjmweb.net/vbindiff/
Source0:        %{name}-%{version}.tar.gz
BuildRequires:  gcc-c++
BuildRequires:  ncurses-devel
BuildRequires:  autoconf
BuildRequires:  automake
BuildRequires:  make
BuildRequires:  perl-Template-Toolkit
BuildRequires:  perl-TimeDate
```

Description text is upstream's: display files in hexadecimal and ASCII (or EBCDIC), two at a time, highlighting differences, working well on large files up to 4 GB.

Body: `%prep` = `%autosetup -n %{name}-%{version}`; `%build` = `autoreconf -fi`, `%configure`, `%make_build`; `%install` = `%make_install`; `%files` = `%license COPYING`, `%doc README.md AUTHORS`, `%{_bindir}/vbindiff`, `%{_mandir}/man1/vbindiff.1%{?ext_man}`. Add a `%changelog` entry dated 2026-11-01, `- troed@... - 3.0~beta5-0`, noting "initial openSUSE package; upstream 3.0 beta5 plus fixes carried in the troed/vbindiff fork".

- [ ] **Step 2: Verify the spec parses and expands with the expected values**

```bash
rpmspec -P vbindiff.spec | egrep '^(Name|Version|Release|License|Source0):'
rpmspec -P vbindiff.spec | grep -A3 '^%files'
```

Expected: `Version: 3.0~beta5`, `Release: 0`, `License: GPL-2.0-or-later`, `Source0: vbindiff-3.0~beta5.tar.gz`, and a `%files` block containing `%license COPYING` and `%{_mandir}/man1/vbindiff.1%{?ext_man}`.

- [ ] **Step 3: Verify the tarball name resolves against a real tarball**

Build the tarball from the branch and confirm `%prep`'s expected directory exists:

```bash
cd ~/dev/vbindiff
git archive --prefix=vbindiff-3.0~beta5/ -o /tmp/vbindiff-3.0~beta5.tar.gz HEAD
tar -tzf /tmp/vbindiff-3.0~beta5.tar.gz | head -1
```

Expected: `vbindiff-3.0~beta5/`. If this ever prints something else, the spec needs an explicit `-n` and the design's fallback applies.

- [ ] **Step 4: Build a source RPM to prove the spec is structurally sound**

```bash
mkdir -p /tmp/rpmbuild/{SOURCES,SPECS,SRPMS}
cp /tmp/vbindiff-3.0~beta5.tar.gz /tmp/rpmbuild/SOURCES/
cp vbindiff.spec /tmp/rpmbuild/SPECS/
rpmbuild --define '_topdir /tmp/rpmbuild' -bs /tmp/rpmbuild/SPECS/vbindiff.spec
```

Expected: `Wrote: /tmp/rpmbuild/SRPMS/vbindiff-3.0~beta5-0.src.rpm`.

- [ ] **Step 5: Commit the spec into the fork's packaging directory for review**

```bash
mkdir -p packaging/opensuse
cp vbindiff.spec packaging/opensuse/vbindiff.spec
git add packaging/opensuse/vbindiff.spec
```

(The OBS package is authoritative at build time; this copy exists so the spec has review history.)

### Task 3: Write the source service

**Files:**
- Create: `packaging/opensuse/_service`

**Interfaces:**
- Consumes: `git rev-parse opensuse` (full SHA).
- Produces: OBS-side files `vbindiff-3.0~beta5.tar.gz` and `_servicedata`.

- [ ] **Step 1: Write `_service` with the branch head pinned**

```xml
<services>
  <service name="tar_scm" mode="disabled">
    <param name="scm">git</param>
    <param name="url">https://github.com/troed/vbindiff</param>
    <param name="revision">FULL_SHA_OF_OPENSUSE</param>
    <param name="version">3.0~beta5</param>
    <param name="filename">vbindiff</param>
  </service>
  <service name="recompress" mode="disabled">
    <param name="file">*.tar</param>
    <param name="compression">gz</param>
  </service>
</services>
```

- [ ] **Step 2: Substitute the branch head for the placeholder**

```bash
cd ~/dev/vbindiff
SHA=$(git rev-parse opensuse)
sed -i "s|FULL_SHA_OF_OPENSUSE|$SHA|" packaging/opensuse/_service
```

- [ ] **Step 3: Verify the pin and the XML**

```bash
SHA=$(git rev-parse opensuse)
grep -q "$SHA" packaging/opensuse/_service && python3 -c "import xml.dom.minidom; xml.dom.minidom.parse('packaging/opensuse/_service')" && echo ok
```

Expected: `ok`. Re-run this check after every future commit that lands on `opensuse` and updates the pin.

- [ ] **Step 4: Commit**

```bash
git add packaging/opensuse/_service
git commit -m "Add the OBS source service pinned to the opensuse branch" -- packaging/opensuse/_service
```

### Task 5: Create the OBS project and land the first build

**Human-executed** (needs `osc`, credentials, and `api.opensuse.org` egress).

- [ ] **Step 1: Create the subproject**

```bash
osc meta prj home:troed:vbindiff -F - <<'EOF'
<project name="home:troed:vbindiff">
  <title>vbindiff</title>
  <description>Visual binary diff, built from the troed/vbindiff fork</description>
  <repository name="openSUSE_Tumbleweed">
    <path project="openSUSE:Factory" repository="snapshot"/>
    <arch>x86_64</arch><arch>aarch64</arch>
  </repository>
  <repository name="16.0">
    <path project="openSUSE:Leap:16.0" repository="standard"/>
    <arch>x86_64</arch><arch>aarch64</arch>
  </repository>
</project>
EOF
```

- [ ] **Step 2: Create the package and add the files**

```bash
osc co home:troed:vbindiff && cd home:troed:vbindiff
osc mkpac vbindiff && cd vbindiff
cp ~/dev/vbindiff/packaging/opensuse/vbindiff.spec .
cp ~/dev/vbindiff/packaging/opensuse/_service .
osc add vbindiff.spec _service
```

- [ ] **Step 3: Push the fork, then re-pin the service to the pushed head**

```bash
cd ~/dev/vbindiff
git remote add fork https://github.com/troed/vbindiff 2>/dev/null || true
git push fork master opensuse
SHA=$(git rev-parse opensuse)
cd ~/obs/home:troed:vbindiff/vbindiff
sed -i "s|<param name=\"revision\">.*</param>|<param name=\"revision\">$SHA</param>|" _service
grep -q "$SHA" _service && echo pinned
```

Expected: `pinned`. The pushed SHA must be the one pinned — a commit that exists only locally cannot be fetched by OBS.

- [ ] **Step 4: Generate the sources and commit**

```bash
cd ~/obs/home:troed:vbindiff/vbindiff
osc service ra
ls            # expect vbindiff-3.0~beta5.tar.gz, _servicedata, _service, vbindiff.spec
osc commit -m "vbindiff 3.0~beta5 from troed/vbindiff"
```

- [ ] **Step 5: Verify the builds**

```bash
osc results home:troed:vbindiff
```

Expected: `succeeded` for both repositories and both architectures. For any failure, `osc buildlog <repo> <arch>`; the two known failure modes are the tarball directory name (add `-n` to `%autosetup`) and a missing `perl-Template-Toolkit`.

- [ ] **Step 6: Record the rpmlint verdict**

OBS runs rpmlint as part of every build; read its section of the log:

```bash
osc buildlog -o rpmlint home:troed:vbindiff openSUSE_Tumbleweed x86_64
```

(or the "rpmlint" log in the OBS web UI for the same repo). Expected: no `E:` lines. Warnings get fixed or explained in the task report.
